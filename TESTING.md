# Проверка TASCA MVP 0.4

## Что проверено автоматически

- **28 проверок интерфейса** (`test_ui_v04.py`): переключение режима просмотра, размер и наличие рамки телефона, отсутствие рамки на широком сайте, переключение обратно, сохранение открытой страницы, скрытие боковых подсказок и работа переключателя без подсказок.
- На широком экране каталог задач показывает **две колонки**, при возврате к телефону он снова сужается.
- При настоящей мобильной ширине 390px сайт занимает весь экран без корпуса телефона, горизонтального переполнения нет.
- Сценарий студента: профиль → лента → раскрываемые фильтры → задача → отклик → согласование → сдача → приёмка → демонстрация завершения.
- Сценарий заказчика: профиль → создание задачи → тестовая модерация → публикация.
- Отдельный сквозной тест (`test_cross_role.py`): реальная связь двух демо-ролей в одном браузере, отклик, выбор исполнителя, сдача и приёмка.
- Ошибок JavaScript в этих тестах не обнаружено.

## Что проверить вручную после публикации на GitHub Pages

- [ ] Открыть главную и прокликать выбор «Телефон / Компьютер» — рамка появляется/исчезает.
- [ ] На компьютере открыть ленту: в широком режиме две колонки, в узком — одна.
- [ ] Скрыть боковые подсказки: переключение экрана всё ещё доступно справа сверху.
- [ ] Перезагрузить страницу: проверить, что данные сценария сохранились в этом браузере.
- [ ] На смартфоне открыть сайт: без рамки и боковых панелей.
- [ ] Проверить регистрацию, создание задачи, отклик и смену роли.
- [ ] Проверить раскрывающиеся блоки: фильтры, материалы, профиль, демо-действия.
- [ ] Проверить, что текст о деньгах везде обозначен как демонстрационный.

Скриншоты лежат в папке `previews`. Тестовые данные синтетические; функция настоящего перевода денег не реализована.
